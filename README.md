# Extasis - Bar El Éxtasis

Proyecto fullstack: Django (backend) + React + Vite (frontend).

Resumen rápido:
- API: Django REST Framework
- Frontend: React 19 + Vite

Instrucciones de desarrollo:

1. Crear entorno Python y dependencias:

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
```

2. Frontend:

```powershell
cd frontend
npm install
npm run dev
```

3. Ejecutar Django (desarrollo):

```powershell
cd backend
python manage.py migrate
python manage.py runserver
```
